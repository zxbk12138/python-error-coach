# Runoob Python 章节映射

来源索引：

`https://www.runoob.com/python3/python3-tutorial.html`

本文件只整理学习主题和诊断重点，不复制教程正文。

## 基础层

| 主题 | 关键前置知识 | 常见问题 |
|---|---|---|
| 环境与运行 | 终端、脚本、解释器 | 当前目录错误、命令与代码位置混用 |
| 基本语法 | 缩进、注释、语句 | 中文标点、缩进不一致、语句结构缺失 |
| 变量与类型 | 名称、赋值、类型 | 未赋值、拼写错误、类型混用 |
| 数字与运算符 | 算术、比较、逻辑 | 优先级、整除、浮点结果 |
| 字符串 | 引号、索引、格式化 | 引号未闭合、格式化占位符 |
| 输入输出 | `input`、`print` | 输入类型、文件模式无输出 |

## 控制流与容器

| 主题 | 关键前置知识 | 常见问题 |
|---|---|---|
| 条件 | 比较、布尔表达式 | 少冒号、缩进、`=` 与 `==` |
| 循环 | `for`、`while`、范围 | 边界、累加器、无限循环 |
| 列表 | 索引、切片、修改 | 越界、复制与引用、方法返回值 |
| 元组 | 不可变序列 | 修改失败、单元素逗号 |
| 字典 | 键值访问 | 键不存在、类型不一致 |
| 集合 | 去重、集合运算 | 无序、不可索引 |
| 推导式 | 可迭代对象、表达式 | 条件位置、可读性 |

## 核心编程

| 主题 | 关键前置知识 | 常见问题 |
|---|---|---|
| 函数 | 参数、返回值、作用域 | 忘记返回、参数数量、局部变量 |
| 模块与包 | 导入、路径、环境 | 模块名冲突、环境不一致 |
| 文件 | 路径、编码、上下文管理 | 文件不存在、未关闭、覆盖 |
| 异常 | `try`、`except`、异常传播 | 捕获过宽、隐藏错误 |
| 迭代器和生成器 | 可迭代协议、惰性求值 | 迭代耗尽、返回类型 |
| 面向对象 | 类、实例、方法 | `self`、实例与类属性混淆 |
| 标准库 | 按任务选择模块 | 版本与 API 不匹配 |

## 章节使用方式

1. 先根据用户代码判断当前主题。
2. 只补当前任务必需的前置知识。
3. 将 Runoob 主题当作索引，不把整章内容塞给用户。
4. 对具体 API 和版本差异，优先查当前官方文档。

学习路径应按目标组合主题，而不是机械地从头读到尾。
