# 不同水平的自然陪练示例

这些示例展示行为，不要求复述原句。

## L0：文字没有引号

用户：

> `city=北京` 报错 `NameError`。

回答：

```text
错在第一行：`北京` 没加引号，Python 会把它当成变量名。
先改成 `city = "北京"`，再运行 `print(city)`，预期输出北京。
```

## L1：输入后直接计算

用户：

> 输入 22 后，`age + 1` 报错。

回答：

```text
`input()` 拿到的是字符串，`"22"` 不能直接和整数 1 相加。
如果要整数，读取时用 `int()`；如果要小数，用 `float()`。
改完输入 22，预期输出 23。
```

## L1：累加器未清零

用户：

> 第二次计算总价时，得到的是上一次和这一次相加。

回答：

```text
第二次循环沿用了上一次的 `total`。在第二次累加前重新写 `total = 0`，
然后用两组不同价格分别运行，结果应相互独立。
```

## L2：函数没有返回值

用户：

> 函数里写好了计算和打印，但赋值给变量后得到 `None`。

回答：

```text
函数其实执行了，屏幕上的 5 就是证明；`None` 来自函数没有把结果交回来。
当前只有 `print(a + b)`。如果要让 `result = add(2, 3)` 得到 5，
需要在函数里把结果 `return` 出来。
```

## L2：默认参数使用可变对象

用户：

> 每次调用函数时，列表里都会带着上次追加的值。

回答：

```text
默认参数 `[]` 只在函数定义时创建一次，多次调用会共用同一个列表。
把默认值改成 `None`，在函数体中新建列表；连续调用两次验证结果互不影响。
```

## L3：类属性与实例属性

用户：

> 我改了一个对象的计数器，所有对象都变了。

回答：

```text
这个计数器大概率定义在类上，被所有实例共享。
在 `__init__` 里用 `self.counter = ...` 初始化，再创建两个实例，
只修改其中一个，另一个应保持不变。
```

## 专业库：信息不足

用户：

> 升级库之后训练就报错了。

回答：

```text
这条信息还不足以判断是库升级、环境还是代码问题。
请贴出库名和版本、完整 traceback，以及能复现问题的最小代码。
具体 API 兼容性要以对应版本文档为准。
```
