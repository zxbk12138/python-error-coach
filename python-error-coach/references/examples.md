# 不同水平的陪练示例

## L0：文字没有引号

用户：

> `city=北京` 报错 `NameError`。

回答：

```text
报错事实：Python 在找一个名为“北京”的变量。
先检查这一处：`=` 右边是不是文字？文字需要加引号。
验证：打印 `city`，预期看到城市名。
```

## L1：输入后直接计算

用户：

> 输入 22 后，`age + 1` 报错。

回答：

```text
报错事实：`input()` 得到字符串，不能直接与整数相加。
先检查这一处：转换应该发生在读取输入时，还是在计算前？
请先用 `type(age)` 显示类型，再决定用 `int()` 还是 `float()`。
验证：输入 22，预期输出 23。
```

## L1：累加器未清零

用户：

> 第二次计算总价时，得到的是上一次和这一次相加。

回答：

```text
报错事实：程序没报错，但第二次累加从旧值开始。
先检查这一处：第二次循环前有没有重新设置 `total = 0`。
验证：用两组不同价格分别运行，每组结果应独立。
```

## L2：函数没有返回值

用户：

> 函数里写好了计算和打印，但赋值给变量后得到 `None`。

回答：

```text
报错事实：函数向屏幕打印了结果，但没有把结果交回调用者。
先检查这一处：函数体内是否使用 `return`。
验证：`result = f(2, 3)` 后打印 `result`，应得到计算结果而不是 `None`。
```

## L2：默认参数使用可变对象

用户：

> 每次调用函数时，列表里都会带着上次追加的值。

回答：

```text
报错事实：默认参数只在函数定义时创建一次，可变默认值会被多次调用共享。
先检查这一处：参数默认值是否是 `[]` 或 `{}`。
方向：默认值改用 `None`，在函数体内新建容器。
验证：连续调用两次，每次结果应相互独立。
```

## L3：类属性与实例属性

用户：

> 我改了一个对象的计数器，所有对象都变了。

回答：

```text
报错事实：变化的值可能定义在类上，被所有实例共享。
先检查这一处：计数器是在 `__init__` 中用 `self` 初始化，还是写在类体中？
验证：创建两个实例，只修改其中一个，观察另一个是否保持不变。
```

## 专业库：信息不足
