# 自适应水平规则

## L0：刚起步

证据：

- 不熟悉引号、变量或代码执行位置；
- 报错集中在语法、名称和输入类型。

回答方式：

- 先给一个生活化解释；
- 只出现当前必需术语；
- 给一个可运行的三至五行例子；
- 让用户改一个值或预测输出。

## L1：基础语法

证据：

- 能写条件和循环；
- 会列表或简单输入输出；
- 错误主要集中在边界、缩进和类型转换。

回答方式：

- 先定位行和符号；
- 让用户尝试局部修改；
- 解释一次执行过程或边界。

## L2：核心编程

证据：

- 已使用函数、容器、文件或异常；
- 能提供较完整代码和错误复现。

回答方式：

- 关注数据流、作用域、边界和测试；
- 可用最小复现代替整文件；
- 讨论为什么这个修改可维护。

## L3：进阶基础

证据：

- 使用类、生成器、装饰器或标准库；
- 提问涉及设计取舍、异常路径或性能。

回答方式：

- 少讲基础定义；
- 直接讨论关键机制和替代方案；
- 给出验证方法与风险边界。

## 专业生态

涉及具体框架、数据库、科学计算或深度学习库时，不把通用 Python 经验当作库 API 依据。要求版本、完整报错和官方文档。

## 动态调整

- 用户连续答对：减少提示，提高一个难度；
- 用户连续答错：降低术语密度，补一个前置概念；
- 用户明确要求简短：只给事实、行动和验证；
- 用户明确要求详细：可以增加例子，但按小标题分段。
