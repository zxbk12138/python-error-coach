# 通用 Python 错误诊断索引

先看完整报错最后一行和文件行号，再选择最相关的类别。不要一次把整个索引发给用户。

## 语法与环境

### SyntaxError

常见证据：

- 缺少冒号、括号或引号；
- 中文全角标点；
- 当前语句结构不完整；
- 关键字拼写错误。

处理：引用报错行和附近符号，只指出一个最可能的语法问题。

### IndentationError

常见证据：

- 同一代码块缩进不一致；
- 空格与制表符混用；
- 条件、循环、函数或类后的代码未缩进。

处理：比较相邻代码块的缩进层级。

### 代码运行位置错误

证据：

- 在 Python 交互提示符中输入 PowerShell 命令；
- 在 PowerShell 中输入 Python 语句；
- 工作目录中没有目标脚本。

处理：先确认当前是终端、Python 交互模式还是编辑器。

## 名称、作用域与类型

### NameError

检查：

- 变量或函数是否先定义；
- 拼写和大小写；
- 是否超出局部作用域；
- 是否把文字误写成变量名。

### TypeError

检查：

- 操作数类型；
- 函数参数数量和类型；
- 是否对 `None` 调用方法；
- 容器与单个值是否混用。

### ValueError

检查：

- 类型转换的输入格式；
- 解包数量；
- 数据范围；
- 函数接收到的值是否符合要求。

### AttributeError

检查：

- 对象类型；
- 方法名；
- 是否把模块、类、实例混淆。

## 字符串与格式化

- 引号是否成对、是否为英文半角；
- 字符串与数字能否直接相加；
- f-string 是否缺少 `f` 或 `{}`；
- 格式化字段与变量名是否一致；
- 转义字符是否符合预期。

## 条件、循环与逻辑

- 条件末尾是否缺少冒号；
- `=` 与 `==` 是否混用；
- 缩进决定代码属于哪个代码块；
- 累加器是否在重复使用前初始化；
- 循环边界是否少一或多一；
- `break`、`continue` 是否改变预期流程；
- 可变对象在循环中是否被意外修改。

## 容器

### 列表与元组

- 索引是否从 0 开始；
- 是否超出序列长度；
- 切片边界是否符合“左闭右开”；
- 元组是否尝试原地修改；
- 方法是否直接修改对象或返回新对象。

### 字典

- 键是否存在；
- 键的类型是否一致；
- 是否错误使用位置索引；
- 遍历时是否修改字典大小。

### 集合

- 是否尝试按索引访问；
- 是否期待固定顺序；
- 存放的元素是否可哈希。

## 函数

- 参数数量与顺序；
- 是否混淆打印与返回值；
- 默认参数是否使用可变对象；
- 局部变量是否被误认为全局变量；
- 递归是否缺少终止条件。

## 文件与模块

- 路径、文件名和扩展名；
- 当前工作目录；
- 编码；
- 是否使用上下文管理器关闭文件；
- 模块名与内置模块冲突；
- 当前 Python 环境是否安装目标包；
- 本地模块路径是否正确。

## 异常

- 捕获范围是否过宽；
- 是否吞掉异常后继续使用无效状态；
- 是否只处理一种异常；
- `raise` 后控制流是否符合预期。

## 类与对象

- 实例方法是否缺少 `self`；
- 类属性和实例属性是否混淆；
- 是否正确调用父类初始化；
- 可变类属性是否被多个实例共享。

## 没有报错但结果错误

要求最小复现：

```text
输入：
预期：
实际：
```

再检查：

- 题目要求是否逐项满足；
- 边界值；
- 数据类型；
- 代码从上到下的顺序；
- 变量是否在预期位置被修改；
- 结果是否真的被打印或返回。
