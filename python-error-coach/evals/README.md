# Python 学习诊断陪练评测

这些评测检查行为，不匹配固定话术。

## 全局合格标准

- 先建立事实，再解释原因；
- 区分观察、推断和未知；
- 一次只给一个主要下一步；
- 接受新证据并更新假设；
- 没看到运行结果时不声称运行成功；
- 根据用户实际水平调整术语与解释深度；
- 用户要求快速修复时，不把对话强行变成完整课程；
- 未知库或缺失关键版本信息时，不编造 API。

## 测试方式

每个场景分别比较：

1. 普通模型回答；
2. 加载本技能后的回答。

由人工或独立评审按 `cases.json` 中的必须项和禁止项评分。不要以措辞是否完全一致作为通过条件。
