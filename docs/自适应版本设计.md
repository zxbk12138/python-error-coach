# 从单一学习记录扩展到通用 Python 初学者

## 目标变化

早期版本根据一份真实零基础学习记录，限定在 Python 前六课。这个范围容易验证，但不能适配其他水平的学习者。

新版不再绑定单个学生，而是使用动态水平判断：

- L0：刚接触输出、变量或输入；
- L1：会类型、条件、循环和简单容器；
- L2：会函数、文件、异常、模块和复杂容器；
- L3：会类、迭代器、生成器或标准库。

水平由实际代码和问题判断，不由用户自称决定。

## 为什么保留真实学习记录

真实记录仍然有价值：

- 提供可信的首批零基础案例；
- 暴露引号、类型、f-string、列表和循环等常见误区；
- 证明作品来自真实需求。

但它不再是作品的上限，而是测试集的一部分。

## Runoob 的使用方式

Runoob Python 教程作为章节索引，用来检查知识地图是否有明显缺口。

使用原则：

1. 不复制整段教程；
2. 主题用于定位前后置知识；
3. 具体讲解结合用户代码重新组织；
4. 涉及版本或第三方库时查当前官方文档；
5. 一次只补当前任务需要的主题。

章节索引见 `python-error-coach/references/runoob-topic-map.md`。

## 自适应机制

### 观察

- 用户是否能写可运行代码；
- 使用了哪些语法结构；
- 报错位于语法、类型、作用域、容器还是环境；
- 用户能否描述输入、预期和实际结果。

### 响应

- L0：比喻和一个最小例子；
- L1：具体行与一个局部修改；
- L2：机制、边界、最小复现和测试；
- L3：设计取舍、异常路径和可维护性；
- 专业库：索取版本与完整报错，查官方文档。

### 调整

- 连续答对时减少提示；
- 连续答错时补一个前置概念；
- 用户要求简短时只给事实、行动和验证；
- 用户要求详细时增加示例，但不倾倒整章内容。

## 兼容性

技能标识继续使用 `python-error-coach`，便于更新既有版本；展示名称改为“Python 学习诊断陪练”，触发描述覆盖通用 Python 学习问题。

## 验收重点

- 零基础能得到足够小的第一步；
- 有基础的用户不会被迫阅读基础定义；
- 复杂错误能落到可验证的最小实验；
- 未经验证的第三方库问题不会编造答案；
- 实际案例、Runoo 章节与测试用例能够互相对应。
