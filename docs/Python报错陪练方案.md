# Python 学习诊断陪练

## 一、作品定位

一个会根据学习者真实代码动态调整讲解深度的 Python 陪练。

它不只服务零基础，也服务已经学过语法、正在学习函数、文件、异常、类或标准库的初学者。

第一版不试图覆盖所有第三方专业生态。遇到 Web、数据分析或深度学习库时，只处理通用 Python 部分，具体 API 以版本和官方文档为准。

## 二、核心问题

Python 学习资料很多，但常见问题不是“没有内容”，而是：

- 新手得到过于抽象的解释；
- 有基础的人被迫阅读基础定义；
- 助手一次给很多建议，用户不知道先做哪一步；
- 直接给完整代码，学习者没有真正理解；
- 对第三方库也不确定时，仍然编造 API。

作品通过“先判断、再陪练”解决：

> 看真实代码 → 估计水平 → 识别问题类型 → 给一个下一步 → 用运行结果验证 → 调整难度

## 三、四层自适应

| 层级 | 用户特征 | 响应方式 |
|---|---|---|
| L0 起步 | 输出、引号、变量、输入尚不熟 | 生活化比喻，一个最小例子 |
| L1 基础 | 会类型、条件、循环、简单容器 | 指出具体行和符号，让用户先尝试 |
| L2 核心 | 会函数、文件、异常、模块 | 讲机制、边界、最小复现和测试 |
| L3 进阶 | 会类、迭代器、生成器、标准库 | 直接讨论设计取舍和异常路径 |

水平由代码证据判断。用户自称“小白”或“学过很多”只作参考。

## 四、支持的主题

### 基础层

- 运行环境、交互模式和脚本模式；
- 语法、缩进、注释；
- 变量、基本类型和运算符；
- 输入输出和格式化；
- 条件与循环。

### 容器层

- 列表、元组、字典和集合；
- 索引、切片、遍历和推导式；
- 可变对象与引用。

### 核心层

- 函数、参数、返回值和作用域；
- 模块、包与环境；
- 文件读写；
- 异常处理；
- 迭代器和生成器；
- 面向对象；
- 标准库。

### 边界

专业库和框架问题需要：

- 库名和版本；
- 完整报错；
- 最小复现代码；
- 官方文档依据。

无法确认时不编造答案。


### 练习题

按四级提示：

1. 方向；
2. 关键语法或数据结构；
3. 一处修改方向；
4. 最小可运行结果及解释。

## 六、Runoob 素材的使用

Runoob Python 教程用于组织知识地图，不作为逐字复制的题库。

处理方式：

1. 用章节检查知识覆盖；
2. 将主题与常见错误对应；
3. 用自己的话和用户代码解释；
4. 涉及版本差异时查当前官方文档。

章节映射见 `python-error-coach/references/runoob-topic-map.md`。

## 七、真实性设计

- 不假设用户水平，只依据可观察证据；
- 缺少信息时先询问；
- 一次只给一个主要下一步；
- 代码改动后要求运行、预测或解释；
- 专业库不确定时明确说明；
- 不复制教程原文；
- 不执行不可信代码。

## 八、比赛演示

准备四个对话：

1. 零基础：f-string 缺少 `f`；
2. 基础：累加器或循环边界错误；
3. 中阶：函数打印但没有 `return`；
4. 边界：第三方库升级报错，正确要求版本并转官方文档。

通过四个案例展示同一技能会改变讲解方式和回答长度。
