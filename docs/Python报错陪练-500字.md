# Python 学习诊断陪练作品说明

## 作品思路

Python学习者水平差异大，固定难度会让新手听不懂，也让有基础的人觉得啰嗦。作品依据真实代码和报错判断层级，在修错、教学、复习测验和规划之间切换。

## 功能说明

学生提交代码、报错或学习目标后，技能区分已知事实与推测，提出少量竞争假设，每次只给一个能区分假设的下一步。修复后通过解释、结果预测或变式练习确认掌握。

## 技术实现

采用平台智能体交互、证据台账和自适应规则。SKILL.md定义快速路径、四种模式、四层水平、自然表达、最小改动、默认简洁、模式提醒、不弹问答和第三方库边界；参考资料提供常见错误、教学方法与GitHub设计参考；评测集覆盖多轮反馈和防幻觉场景。

## 使用说明

用户粘贴代码、完整报错和预期结果，或说明学习目标。技能给一个修改方向或概念，再根据用户的新结果更新判断。

## 提示词与迭代

核心提示词为“依据真实证据判断水平，自然简洁，代码块清晰，不展示思维链，一次只给一个下一步，并用运行或解释验证”。实机测试覆盖零基础、类型、函数、生成器、未知库和补充上下文，根据失败回答收紧边界。
