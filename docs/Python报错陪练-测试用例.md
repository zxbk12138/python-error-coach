# Python 学习诊断陪练测试用例

## 一、零基础与基础语法

| 编号 | 用户输入 | 期望行为 |
|---|---|---|
| P01 | `city=北京` 报 `NameError` | 指出文字需要引号，不一次讲完变量章节 |
| P02 | `age=input()` 后执行 `age+1` | 指出 `input()` 返回字符串，让学生判断转换方式 |
| P03 | `print("你好，{name}")` 输出字符原样 | 指出缺 `f` 开关 |
| P04 | `print(f"3+5")` 输出 `3+5` | 指出缺少 `{}` |
| P05 | `for i in range(5)` 后少冒号 | 指出循环语句缺少冒号 |
| P06 | 第二次累加前没有设置 `total=0` | 解释累加器初始化的作用 |

## 二、容器与控制流

| 编号 | 用户输入 | 期望行为 |
|---|---|---|
| P07 | 三元素列表访问 `foods[3]` | 引导检查索引从 0 开始 |
| P08 | `len("foods")` 得到 5 | 区分数字符串和数列表元素 |
| P09 | 遍历字典时增删键并报错 | 指出不能边遍历边改变字典大小，安排先收集再修改 |
| P10 | `while` 程序一直不停 | 检查循环变量更新和退出条件 |
| P11 | 切片结果比预期少一个元素 | 解释左闭右开边界 |
| P12 | 程序不报错但漏题目里的单位 | 要求逐项对比题目、输入和输出 |

## 三、函数、文件与异常

| 编号 | 用户输入 | 期望行为 |
|---|---|---|
| P13 | 函数打印结果但调用后得到 `None` | 区分打印与返回值 |
| P14 | 默认参数 `[]` 在多次调用间保留旧数据 | 指出可变默认对象，要求构造两个测试调用 |
| P15 | 文件读取报 `FileNotFoundError` | 检查路径、名称和当前工作目录 |
| P16 | `try/except` 捕获后程序继续输出错误结果 | 检查异常是否被过宽捕获、后续状态是否有效 |
| P17 | 从其他目录导入本地模块失败 | 检查运行入口、模块路径与包结构，不直接乱装包 |

## 四、进阶与边界

| 编号 | 用户输入 | 期望行为 |
|---|---|---|
| P18 | 一个实例修改计数器后所有实例都变化 | 区分类属性与实例属性，并给两个实例的验证方法 |
| P19 | 生成器第二次遍历没有输出 | 说明生成器只能消费一次，验证 `list()` 或重新创建生成器 |
| P20 | 升级第三方库后训练报错 | 不编造 API；索取库名、版本、完整 traceback，建议查官方文档 |
| P21 | 用户说“我是小白，请把 Python 全讲一遍” | 不倾倒课程；询问目标与已有代码，只安排一个切入点 |
| P22 | 用户直接要求高级写法和新手写法 | 根据代码证据分别给出简洁方案，不强制降低到零基础语气 |

## 合格标准

- 技能能在不依赖固定用户资料的情况下自然触发；
- 至少四层水平中每层都有正确响应；
- 信息不足时先询问，不编造；
- 一次只给一个主要下一步；
- 不把 Runoob 原文大段复制给用户；
- 第三方库不确定时明确转查官方文档；
- 每次修改都能给出验证方法；
- 同一用户水平变化后，讲解深度能随之调整。
